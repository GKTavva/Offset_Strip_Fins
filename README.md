# Offset Strip Fins — j, f & Goodness Factor Calculator (LPD Air-Side)

This repository hosts a lightweight web-based tool that implements **CFD-derived correlations** for predicting the **Colburn j factor**, **Fanning friction factor f**, and **Goodness factor (j/f)** for **rectangular offset strip fins (OSFs)** used in compact heat exchangers.

The correlations are based on a comprehensive **numerical (CFD) study** and are applicable to **low-power-density (LPD) air-side configurations**.
